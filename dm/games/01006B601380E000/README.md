# Kirby's Return to Dream Land Deluxe (`01006B601380E000`)

Base game 1.0.0 (v0), no update known. SDK 13.3.5. HAL Laboratory's own engine on NintendoWare (G3d, Font, Ui2d, Vfx2, Fxt 1.57.0) with NVN graphics. Same engine family as [Kirby and the Forgotten Land](../01004D300C5AE000/README.md), whose note covers the engine. Modules `main`, `subsdk0` (NintendoSDK_movie, the WebM movie module) and `sdk`.

**Status (current): plays on Android.** The profile and the runs below are Peanuts Native's (igawa6/peanuts-native, its pull request #34; run by that contributor only, not yet in this tree's builds). On an AYN Thor (Adreno 740) it boots, passes the title and the file select, and plays the first stage, on the system driver and on Turnip 27.0.0 R2, with the firmware's shared fonts (without them it crashes at startup, below). Not run on the Mac, nor with this tree's build. The profile started as a provisional one; its memory layout is still the guess below.

## Files and shaders

- RomFS: 6,084 files, 4.97 GB. 3,051 `.cmp` containers under `gfx/`, `ptcl/` and `lyt/`, the loose `shader/` files, and shaders embedded in `main`.
- `shader_split.py` found 47,099 shaders: 62 compute, 32,861 pixel, 14,176 vertex. By source: `gfx` 36,950, `ptcl` 9,693, `lyt` 323, `shader` 78, `main` 54, `gfxshader` 1. It found 36,174 variation pairs and no `[RED]` line.
- **The `ptcl` shaders on the phone (Peanuts Native's issue #78):** the 9,693 `ptcl` shaders are in the 246 particle archives' size-prefixed LZ4 frames. Peanuts Native 0.1.3's on-device Python had no `lz4.frame`, so its Prepare left those archives closed and made a library of 37,406 shaders, exactly 9,693 short (all 27 missing keys of the report's log are `/ptcl/` ones). With the module, Peanuts Native's on-device split on the Thor read all 246 archives and a full Prepare made all 47,099 (`[0, 0]` missing); the first stage's inhale streaks and particles then drew. This tree's split reads LZ4 frames with `lz4.block` alone (`shader_split.py` `lz4_frame`), which the phone's Python has; an on-device Prepare of this game was not run here.

## Frame rate

- **Current (Turnip, first stage):** the overlay shows 60 fps, but 158 to 162 of every 300 frames take longer than 16.7 ms (p99 about 20 ms), so the game runs at 50 to 60 fps. Not profiled yet.

## Found on this game

- **Resolved: startup crash without firmware fonts (Android).** With no firmware in the app, the host serves a stand-in for every shared font type; right after nnMain the game dereferences a null glyph for U+25A1 and crashes (`CRASH sig=11 addr=0x38 pc=main+0x4a78c8`, `x1=0x25a1`), as [Echoes of Wisdom](../01008CF01BAAC000/README.md) did. The game's own fault; this tree's stand-in standard font has U+25A1 (Noto Sans Math and Symbols merged in, Echoes of Wisdom's note), so the game should start without the firmware's fonts here, which was not run (Peanuts Native held the title back without firmware fonts instead).

## Open

- **The system driver draws the ship and the character as black silhouettes** (Peanuts Native, the Thor, Qualcomm's driver, driver ID 8, a complete library): the world map and stage selection draw right; Turnip V39 draws the ship right with the same library. No missing-shader line, no failed pipeline and no crash in 195 s. The cause is not known.
- `[RED] vk: … texture ID … has no view of shape …: it reads as unbound` on both drivers: a 16x16 cube texture (6 layers) sampled through a view of another target, from two shaders; what it draws, and whether anything looks wrong, is not checked.
- Frame pacing (above), memory layout and pool sizes (the sibling's, not checked against this game).
- Only the title, the file select and the first stage were played: later worlds, movies, the Magolor Epilogue, Merry Magoland and saves over several sessions are untested.
